# Clipboard — Landing Page

**Short Description**

- This is a small, static landing page project containing a single-page HTML layout and accompanying CSS styles. It is intended as a simple front-end example or template.

**How to View**

- Open the site locally by double-clicking `index.html` or run a simple local server or Go Live.

**Project Structure**

- `index.html`: main landing page
- `style.css`: main stylesheet
- `images/`: image assets used by the page
- `design/`: design sources and mockups
- `style-guide.md`: design/style notes

**Technologies**

- `HTML5` — semantic markup and structure
- `CSS3` — responsive styling and layout
